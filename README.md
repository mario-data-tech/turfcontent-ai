# TurfContent AI

AI-powered horse racing analytics and automated short-video content generation.

## MVP V0.3 - Mobile First
Herramienta de análisis Turf cuantitativo y generación automatizada de contenido vertical (9:16).

### Arquitectura
- **Backend:** FastAPI, Python 3.11, PostgreSQL.
- **Frontend:** React, TypeScript, Vite, Tailwind CSS.
- **Motor:** Análisis cuantitativo con cálculo de *Market Edge*.
